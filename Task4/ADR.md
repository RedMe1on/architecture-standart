### <a name="_qmphm5d6rvi3"></a>**Решение**
Context.puml и Container.puml

Отправка файла по sftp в сервисы кол-центров позволят разным системам работать по согласованным ставкам. Канал защищенный SFTP.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
Опишите здесь наиболее важные альтернативные решения.

1. Реализовать выгрузку файла на nfs с последующей отправкой файла в кол-центры (можно совместить такой вариант с текущей схемой - export модуль может сохранять файл на nfs и отправлять его в сервисы партнерские)

2. Дать доступ кол-центрам к nfs, где будут лежать выгружаемые файлы с актуальными ставками и они сами будут ходить на него по запросу из их систем (Нужна реаизация на стороне партнера)


**Недостатки, ограничения, риски**

1. Если вариант без nfs - партнер может не получить файл из-за сбоя своих сервисов. Либо получить файл с другими ставками
